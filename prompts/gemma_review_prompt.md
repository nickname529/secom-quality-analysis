# Gemma 비판적 검토 프롬프트

역할: 공개 반도체 제조 품질데이터 분석의 비판적 검토자.

아래 자료는 Python으로 실제 계산한 UCI SECOM 분석 결과와 코드다. 다음 규칙을 지켜라.

1. 제공되지 않은 수치, 변수 의미, 공정 조건, 센서명, 장비명, 원인을 만들지 마라.
2. 익명 변수의 예측 연관성을 인과관계로 해석하지 마라.
3. Random Forest score와 임계값을 보정된 불량확률로 부르지 마라.
4. 테스트셋의 FAIL 표본이 작다는 점과 timestamp 그룹·lot/batch ID 부재를 고려하라.
5. 계산이 필요하면 새 숫자를 추정하지 말고, 추가 Python 검증 항목으로 제안하라.

다음 관점으로 공격적으로 검토하라.

- 결측 대치, 상수 제거, scaling, 모델 선택, 임계값 선택에서 데이터 누수가 있는가?
- FAIL Recall, Precision, F1, Balanced Accuracy, ROC-AUC, AP, PR-AUC 해석이 정확한가?
- 0.5 임계값과 품질 우선 후보 임계값의 비교가 공정한가?
- False Negative 분석을 보고 같은 테스트셋으로 모델을 고친 흔적이 있는가?
- 시간순 민감도 분석의 약점과 대안 설명은 무엇인가?
- 변수 후보 안정성 규칙이 과장되어 있지 않은가?
- 현재 결론을 반박할 수 있는 대안 가설은 무엇인가?
- 다음 실행 전에 Python으로 확인할 항목을 우선순위 5개로 정리하라.

응답 형식:

1. 치명적 문제
2. 중요한 해석 위험
3. 잘 통제된 점
4. 추가 검증 5개
5. 결론을 더 절제한 문장
