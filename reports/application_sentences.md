# SK하이닉스 품질보증 지원서용 사실 기반 문장 초안

아래 문장은 프로젝트 코드를 직접 재실행하고 각 판단을 본인의 말로 설명할 수 있을 때만 사용한다.

> UCI SECOM 공개 데이터 1,567건과 원본 파일 기준 590개 익명 변수를 대상으로 불량 스크리닝 미니 프로젝트를 진행했습니다. FAIL이 104건(6.64%)뿐인 불균형과 결측 41,951셀(4.54%), 상수 변수 116개를 먼저 점검하고, 결측 대치와 상수 제거를 학습 fold 안에서 수행해 데이터 누수를 통제했습니다. Dummy, class-weighted Logistic Regression, Random Forest를 train-only 반복 층화 교차검증으로 비교하고, FAIL Recall 80%라는 분석 가정에 맞춘 후보 임계값도 테스트셋을 보지 않고 정했습니다. 잠금 테스트셋에서 Random Forest는 FAIL 21건 중 17건을 탐지했지만 145건의 오탐과 4건의 누락이 발생해 Recall 80.95%, Precision 10.49%의 trade-off를 확인했습니다. `feature_059` 등을 원인이 아닌 후속 점검 후보로 제한하고, 시간순 holdout에서는 Recall 47.06%·Precision 4.60%로 낮아진 결과까지 공개해 batch 정보와 비용 기준 없이는 현장 적용을 주장할 수 없다고 결론냈습니다.

## 짧은 3문장 버전

> 공개 SECOM 데이터 1,567건을 분석하며 결측 41,951셀과 상수 변수 116개를 먼저 점검하고, 모든 전처리와 모델 선택을 학습 fold 안에서 수행해 데이터 누수를 통제했습니다. 품질 우선 후보 임계값에서 테스트 FAIL 21건 중 17건을 찾았지만 오탐 145건과 누락 4건이 발생해 Recall 80.95%와 Precision 10.49%의 trade-off를 혼동행렬로 검증했습니다. 시간순 holdout에서 성능이 낮아진 결과와 익명 변수의 인과 해석 한계까지 공개하며, 높은 수치보다 검증 범위와 추가검사 비용을 함께 판단했습니다.
